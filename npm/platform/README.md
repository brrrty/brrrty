# @brrrty/PLATFORM

The PLATFORM binary for [Brrrty](https://brrrty.com), a fast static site generator that builds your existing 11ty site.

Don't install this package directly. Install [`brrrty`](https://www.npmjs.com/package/brrrty), which depends on it for PLATFORM and runs this binary for you:

```sh
npm install --save-dev brrrty
```
