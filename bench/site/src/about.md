# About this site

{{ site.title }} is a made-up blog. Its posts are generated by `bench/generate.mjs` from a fixed seed, so every build of it has the same input. It exists to time static site generators on something shaped like a real long-running blog:

- {{ collections.posts | size }} posts in Markdown, with code in eight languages
- tag and category pages, paginated
- an Atom feed and a sitemap

Nothing here is about anyone real.
